# Change Log

All notable changes to the "cursor-alternate-file" extension will be documented in this file.

## [1.0.0] - 2024-12-19

### Added
- Initial release of Cursor Alternate File extension
- Automatic file tracking functionality
- "Switch to Alternate File" command for quick file switching
- Seamless integration with VS Code's file system
- Support for all file types
- Real-time tracking of current and alternate files

### Features
- **File Tracking**: Automatically tracks the current file and the last visited file
- **Quick Switching**: Single command to switch between current and alternate files
- **Continuous Tracking**: Maintains file pair tracking as you work
- **Error Handling**: Graceful error messages when no alternate file is available
- **VS Code Integration**: Works with Command Palette and keyboard shortcuts

### Technical Details
- Built with TypeScript and VS Code Extension API
- Compatible with VS Code 1.89.0 or higher
- No additional configuration required
- Lightweight and non-intrusive
